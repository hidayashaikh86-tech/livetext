Instant Text Loading & 50MB+ File Support

August 2026

We've completely overhauled the synchronization engine behind Shareli to prioritize speed above all else.

The Problem with Large Files

Previously, if a room contained large files (e.g., 50MB+), joining the room required downloading the entire room history before you could see any messages. For users on slower networks, this meant staring at a blank screen for several seconds.

Streaming History & Skeleton Loaders

Today, we've fixed this. We introduced a new Streaming History engine. When you join a room, Shareli now instantly streams text messages first. Large files are processed asynchronously in the background. While the files are loading, you'll see a beautiful "Skeleton Loader" placeholder so you know exactly what is happening without the page freezing.

This means you can instantly read text and code snippets, even if there is a massive 50MB+ file currently being downloaded and decrypted in the background.

Try it out!

The update is live right now. Go drop a massive file into a room and open the link on your phone to see how instantly the text appears!
